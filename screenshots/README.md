# Screenshots

Bu klasör sunum, README ve teslim dokümanları için ekran görüntülerini içerir.

## Önerilen ekran görüntüleri

| Dosya adı (öneri) | İçerik |
|-------------------|--------|
| `01-landing.png` | Ana sayfa (hero + özellikler) |
| `02-dashboard.png` | Dashboard + presence |
| `03-room-chat.png` | Oda detay + chat paneli |
| `04-discover.png` | Discover sayfası |
| `05-friends-dm.png` | Friends veya Messages |
| `06-admin-reports.png` | Admin rapor listesi |

## Nasıl eklenir

1. Uygulamayı local çalıştırın (`npm run dev`).
2. Demo hesapla giriş yapın.
3. İlgili sayfayı açın ve ekran görüntüsü alın.
4. PNG dosyalarını bu klasöre kaydedin.
5. İsteğe bağlı: README veya sunum slaytlarına referans verin.

> Ekran görüntülerinde gerçek `.env`, token veya hassas veri bulunmamalıdır.
